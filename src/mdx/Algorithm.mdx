# Algorithm

## Tree

### DFS

**前序遍历: 用于复制树和创建树**

```js
// no-collapse
function preOrder(node) {
  if (node) {
    console.log(node.value); // 访问节点
    preOrder(node.left); // 遍历左子树
    preOrder(node.right); // 遍历右子树
  }
}
```

**中序遍历: 对于二叉搜索树 (BST)，中序遍历会按照升序返回节点的值**

```js
// no-collapse
function inOrder(node) {
  if (node) {
    inOrder(node.left); // 遍历左子树
    console.log(node.value); // 访问节点
    inOrder(node.right); // 遍历右子树
  }
}
```

**后序遍历: 适用于删除树，或者在处理树节点的子节点时使用**

```js
// no-collapse
function postOrder(node) {
  if (node) {
    postOrder(node.left); // 遍历左子树
    postOrder(node.right); // 遍历右子树
    console.log(node.value); // 访问节点
  }
}
```

### BFS

**层序遍历: 常用于广度优先搜索**

```js
// no-collapse
function levelOrder(root) {
  if (!root) return;
  const queue = [root];
  while (queue.length > 0) {
    const node = queue.shift(); // 取出队列的第一个节点
    console.log(node.value); // 访问节点
    if (node.left) queue.push(node.left); // 加入左子树
    if (node.right) queue.push(node.right); // 加入右子树
  }
}
```
