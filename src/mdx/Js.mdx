### iterables, enumerable, for in ,for of 概念辨析

#### 可迭代对象 (Iterables)

> 可迭代对象代表的是"集合"或"序列"的概念  
> 可以用 **for...of** 循环遍历的对象

设计目的：允许按顺序访问一系列值，通常是集合类数据结构。需要一种标准方式来逐个访问其中的元素

合理推断：

- 数组是元素的有序集合，所以自然应该可迭代字符串可以看作字符的序列，所以应该可迭代
- Map 和 Set 是显式设计用来存储集合数据的，所以应该可迭代
- NodeList 和类数组对象表示元素列表，所以它们应该可迭代

#### 可枚举属性 (Enumerable Properties)

> 可枚举性是关于对象属性"可见性"的概念。  
> 可以用 **for...in** 循环遍历的属性

设计目的：控制对象属性在反射和遍历操作中是否可见。
本质特征：

- 与对象的"接口"设计相关
- 决定哪些属性是对象"公开 API"的一部分
- 哪些属性是"内部实现细节"

合理推断：

- 直接添加到对象上的属性，通常是你想让它们被访问的，所以默认可枚举
- 语言内置方法和原型属性如果都可枚举，会在使用 for...in 时"污染"结果，所以设为不可枚举
- 通过 defineProperty 手动定义的属性默认不可枚举，因为它们往往是为了精确控制

### 闭包

通过闭包模拟类

```js
function createPerson(name) {
  // 私有变量
  let age = 0;
  // 构造函数
  return {
    // 实例方法
    greet() {
      console.log(`Hello, my name is ${name} and I am ${age} years old.`);
    },
    // 设置年龄的方法
    setAge(newAge) {
      age = newAge; // 修改私有变量
    },
    // 获取年龄的方法
    getAge() {
      return age; // 返回私有变量
    },
  };
}

const alice = createPerson("Alice");
alice.greet(); // 输出: Hello, my name is Alice and I am 0 years old.
alice.setAge(30);
console.log(alice.getAge()); // 输出: 30
alice.greet(); // 输出: Hello, my name is Alice and I am 30 years old.
```

### apply, call, bind

> 你可以直接把 `const boundFn = fn.bind(thisArg, arg1, arg2)` 看作  
> `const boundFn = (...restArgs) => fn.call(thisArg, arg1, arg2, ...restArgs)`

```js
function.apply(thisArg, [argsArray]) // 立即执行, argsArray 是数组
function.call(thisArg, arg1, arg2, ...) // 立即执行, 逐个传参
function.bind(thisArg, arg1, arg2, ...) // 返回一个新函数, 逐个传参
```

bind 只会生效一次，之后的绑定不会再改变 this 的指向

bind 追加参数

```js
function greet(greeting, punctuation) {
  console.log(`${greeting}, my name is ${this.name}${punctuation}`);
}

const person = { name: "Alice" };

// 第一次 bind，预设了第一个参数 "Hello"
const boundGreet = greet.bind(person, "Hello");

// 调用时传入第二个参数 "!"
boundGreet("!"); // 输出: "Hello, my name is Alice!"

const boundGreet2 = greet.bind(person, "Hi", "!!!");
boundGreet2(); // 输出: "Hi, my name is Alice!!!"
```

### 浮点数精度问题

0.1 + 0.2 不等于 0.3

```js
const isEqual = (a, b) => Math.abs(a - b) < Number.EPSILON;
isEqual(0.1 + 0.2, 0.3);
```

```js

```

### 尾递归优化

把普通递归函数转化成支持尾递归的函数

> 实际尾递归在浏览器不一定支持

**示例: fibonacci**

```js
function fib(n) {
  if (n < 2) return n;
  return fib(n - 1) + fib(n - 2);
}
```

```js
function fib(n) {
  return fibImpl(n, 0, 1);
}
function fibImpl(n, a, b) {
  if (n === 0) return a;
  return fibImpl(n - 1, b, a + b);
}
```

## 疑问

为什么不能直接用 `obj.hasOwnProperty(key)` 而是要用 `Object.prototype.hasOwnProperty.call(obj, key)`

```js collapse
// 情况1：对象覆盖了 hasOwnProperty 方法
let obj1 = {
  hasOwnProperty: function () {
    return false;
  },
  prop: "exists",
};

console.log(obj1.hasOwnProperty("prop")); // 总是返回 false
console.log(Object.prototype.hasOwnProperty.call(obj1, "prop")); // 正确返回 true

// 情况2：无原型对象
let obj2 = Object.create(null);
obj2.prop = "exists";

// console.log(obj2.hasOwnProperty('prop')); // 这行会抛出错误
console.log(Object.prototype.hasOwnProperty.call(obj2, "prop")); // 正确返回 true

// 情况3：正常对象
let obj3 = { prop: "exists" };

console.log(obj3.hasOwnProperty("prop")); // 返回 true
console.log(Object.prototype.hasOwnProperty.call(obj3, "prop")); // 也返回 true
```
